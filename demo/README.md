# Obsidian-to-LaTeX converter demonstration

This **standalone demonstration** is not your thesis. Use the `MAIN.tex` and
`config.tex` included **together**. Do not combine the thesis `scrbook` master
file (which uses `\ifeng`, `\mainmatter`, and a second `biblatex` setup) with
this minimal `scrartcl` configuration.

The supplied `MAIN.bib` is the Zotero-exported Nielsen/Chuang entry provided
by the author, with citation key `nielsenQuantumComputationQuantum2010`.

## Folder layout

- `MAIN.tex`, `config.tex`, `MAIN.bib`: standalone article master, packages,
  bibliography.
- `demo_note.md`: Obsidian source. Its figure embed uses `|place:here`
  **only for this compact demonstration**, to keep the figure below the title.
  This does not alter the converter's default top-of-page placement for a thesis.
- `Chapters/Demo.tex`: generated by `md_to_latex_clipboard.py` from the note.
- `Chapters/Figures/demo_pulse.svg`: source artwork.
- `Chapters/Figures/demo_pulse.pdf`: the vector PDF created from the SVG.
- `Chapters/Figures/svg_to_pdf_batch.py`: SVG-to-PDF helper, installed next
  to the figures as requested.
- `.vscode/settings.json`: LaTeX Workshop recipe that writes to `build/`.
- `build/MAIN.pdf`: confirmed compiled output; `assets/compiled-example.png`:
  screenshot-ready page preview.

## Build in VS Code

1. Extract the folder, then **File → Open Folder** in VS Code. Select the
   extracted folder, not a parent directory or the thesis workspace.
2. Open its `MAIN.tex` (the short one that begins with `scrartcl`).
3. Select `pdflatex → biber → pdflatex ×2` in LaTeX Workshop.
4. Open `build/MAIN.pdf`. The published repository omits generated build artifacts; compare against `../assets/compiled-example.png`.

If running manually from the demo root:

```sh
mkdir -p build
python3 Chapters/Figures/svg_to_pdf_batch.py  # after updating SVGs
pdflatex -halt-on-error -output-directory=build MAIN.tex
biber --input-directory=build --output-directory=build MAIN
pdflatex -halt-on-error -output-directory=build MAIN.tex
pdflatex -halt-on-error -output-directory=build MAIN.tex
```

To regenerate the LaTeX from the Markdown source (optional):

```sh
python3 ../md_to_latex_clipboard.py demo_note.md --root . --strict > Chapters/Demo.tex
```

The converter must be installed separately; it does not invoke `pdflatex` or
Inkscape itself. This demonstration requires LaTeX packages `scrartcl`,
`mathtools`, `graphicx`, `float`, `biblatex`, and their dependencies; Biber is
needed for bibliography processing.
